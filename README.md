# PowerBI Generator

Generador de proyectos Power BI (PBIP: modelo semántico TMDL + informe PBIR) para uso del
equipo: pipeline por roles, especificación confirmada antes de generar, generación determinista
y control de calidad (validación, tests DAX, capturas) antes de entregar.

Estado: fase de análisis. Ver [docs/01-analisis-viabilidad.md](docs/01-analisis-viabilidad.md).
